Closing: this is already possible. Zonal velocity sits at tracer latitudes, so a tracer row needs to be at 0°. `ystart` is the grid's southern edge, so with `Grid(resolution=r, ystart=...)` choose `ystart = -(n + 0.5) * r` for a whole number n (e.g. `ystart = -10 - 1/24` at 1/12°). With the default `ystart` (`-leny/2`), it happens whenever the number of rows is odd.
