Widening this a little: `DepthEditCommand` and `MaskEditCommand` both apply edits one cell at a time in `__call__` (`edit_command.py`), over a list of `(j, i)` tuples built with `np.argwhere`. #106 made storing large edits cheap, but applying them is still per cell. The fix for both: hold the indices as arrays and apply each edit with one array assignment, keeping undo through the stored old values.
